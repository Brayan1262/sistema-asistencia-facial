# Sistema de Asistencia Facial

Sistema web para el control de asistencia en una institucion educativa usando reconocimiento facial.

## Tecnologias

- Java 21
- Spring Boot
- MySQL
- Python 3.12
- Flask
- OpenCV
- HTML, CSS y JavaScript

## Estructura del proyecto

- backend-java: API principal del sistema.
- facial-service-python: microservicio de reconocimiento facial.
- frontend: interfaz web.
- database: scripts SQL.
- docs: documentacion del proyecto.
